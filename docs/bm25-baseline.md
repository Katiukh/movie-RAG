## Наблюдения

«Хоррор» и «роуд-муви» находят фильмы по жанровым словам из описаний.
В индексируемых полях нет токенов «неглупый», «ужастик», «программист», «хакер».
Есть словоформы «ужастики», «программистке», «хакерам», «хакеры», но raw tokenizer их не объединяет.
В запросе «уютное осеннее кино» совпадает только «кино» (69 документов): настроение не учитывается.
Для «программисты и хакеры» встречается «хакеры», но общее «и» добавляет нерелевантные совпадения.
Эти ограничения оставлены намеренно для сравнения с будущими вариантами retrieval.
