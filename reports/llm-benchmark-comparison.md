# LLM relevance filter: сравнение с retrieval backends

Реальный запуск от 2026-10-02: 500 фильмов и тот же gold из 50 запросов.
LLM работает локально через Ollama (`qwen3:8b`), возвращает только `selected_ids`.
Оценивается финальная выдача приложения: Hybrid top-20 → BGE reranker top-10
→ LLM relevance filter. Retrieval, reranker, prompt и gold в ходе оценки не менялись.

## Методика

[Разметка и ограничения gold](../data/eval/README.md) одинаковы для всех режимов:
10 near_exact, 25 paraphrase, 15 semantic; 41 запрос с одним positive и 9 с несколькими.
`Recall@K = |relevant_ids ∩ retrieved_ids[:K]| / |relevant_ids|`.
Overall и группы — среднее по запросам (macro average). Таблицы округлены
до трёх знаков; разности вычислены по полным значениям.

LLM выбирает от 0 до 10 фильмов независимо от cutoff метрики, сохраняя порядок reranker.
Поэтому для LLM в колонке Recall@20 стоит прочерк: кандидаты с позиций 11–20
модели не передаются. Формально вычисленный Recall@20 дублирует Recall@10
и не добавляет информации; остальные backends при Recall@20 имеют бюджет выдачи 20.
Все выбранные IDs проверены как подмножество прежнего reranker top-10 для каждого запроса.
LLM не оценивает ответы как judge: результат сравнивается с неизменной разметкой.

## Параметры

| Этап | Настройки |
| --- | --- |
| Dense | `BAAI/bge-m3`, batch size 8, существующий кэш embeddings |
| Hybrid | по 20 кандидатов BM25/Dense, RRF k=60 |
| Reranker | `BAAI/bge-reranker-v2-m3`, 20 кандидатов, batch size 4, max length 512, CUDA |
| LLM | локальный `qwen3:8b`, top-10, один `/api/chat` на запрос, timeout 60 с |
| Inference LLM | temperature 0.2, think=false, num_ctx=8192, num_predict=4096 |
| Поля LLM | movie_id, title, what, about, why, not_for |

## Изменение после LLM-фильтра

Разница относительно Hybrid + Reranker, в процентных пунктах.
Recall@10 сравнивает один и тот же бюджет из десяти кандидатов до и после фильтра.

| Срез | Δ Recall@1 | Δ Recall@3 | Δ Recall@5 | Δ Recall@10 |
| --- | ---: | ---: | ---: | ---: |
| overall | +1.17 | +0.33 | +0.73 | -2.00 |
| near_exact | +0.00 | +0.00 | +0.00 | +0.00 |
| paraphrase | +0.00 | +0.00 | +0.00 | +0.00 |
| semantic | +3.89 | +1.11 | +2.44 | -6.67 |

Overall Recall@1 вырос с 0.841 до 0.852 (+1.17 п.п.), а Recall@10 снизился
с 0.917 до 0.897 (−2.00 п.п.). Near_exact и paraphrase сохранили показатели;
потери полноты пришлись на semantic. Фильтр улучшил первые позиции после удаления
части кандидатов, но отверг и некоторые размеченные positives.

## Где LLM исключила gold positives

| Query ID | Запрос | Recall@10 до → после | Исключённые positives |
| --- | --- | ---: | --- |
| q038 | анимационная история о героях-животных, сталкивающихся с жестокостью или опасностями | 1.000 → 0.667 | Удивительная история Мароны |
| q048 | роуд-муви о поездке ради встречи с отцом или матерью | 1.000 → 0.333 | До встречи на Венере; Несносный дед |

Эти примеры показывают расхождение отбора с gold; промпт и разметка под результаты
не подгонялись. Recall не измеряет precision и не доказывает корректность каждого
оставленного фильма. В gold могут отсутствовать другие релевантные документы;
независимая человеческая экспертиза разметки ещё не проводилась.
